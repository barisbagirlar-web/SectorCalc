    Runtime probes

      What green means

      • Firebase Auth — client config present; operators can sign in.
      • Firestore — named DB reachable under admin rules.
      • Paddle token — checkout overlay can initialize.
      • Gate hash — passphrase unlock is configured.
      • Tool registry — public calculator inventory loaded.

      Credit adjustment runbook

      1. Open Users & credits and search by email.
      2. Click Adjust to fill UID + current balance.
      3. Prefer delta for refunds/promos; use set absolute only for corrections.
      4. Write a reason (ticket ID). Submit. Confirm a new audit row appears.
      5. Ask the customer to hard-refresh /account.html.

      Checkout triage

      • Sandbox: use Paddle test card 4242…; never use live cards in sandbox.
      • Overlay must not pass successUrl (Paddle 500).
      • If credits missing after paid checkout, check browser ledger then cloud profile; grant delta with audit reason.
      • Vendor truth lives in Paddle — open External consoles → Paddle for disputes.
