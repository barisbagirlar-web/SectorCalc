What the result means

Higher heat input usually means slower cooling and more distortion risk. Compare against the qualified WPS range — not against a generic “good weld” myth.

What moves the result

Travel speed dominates. Current is next. Efficiency differences between processes shift HI even at identical V/I/v.

Weld thickness sizing balances structural demand against code minimums. SC-001 computes required throat thickness from design load and allowable shear, converts to fillet leg for equal-leg joints, compares against interpolated AWS D1.1 Table 2.1 minimum legs, and reports utilization — all as deterministic preview calculations, not certified WPS or PE-stamped designs.

Engineering preview · Reference AWS D1.1 minimum legs are approximate table nodes · ISO 5817 quality levels not auto-selected · Verify with the code edition in force and qualified procedures before fabrication · Not for production approval or regulatory submission.

Fillet leg vs throat thickness

On drawings, fillet welds are usually specified by leg size (z) — the length of each leg on an equal-leg fillet. Structural capacity, however, is governed by throat thickness (a) — the minimum cross-section through the weld root to face, measured along the bisector of the legs.

For an equal-leg fillet with legs at 90°, the theoretical throat lies at 45° and:

throat a = leg z × cos(45°) = leg z × 0.707

SC-001 uses factor 0.707 for fillet joints. Butt joints in full-penetration idealization use factor 1.0 (throat equals leg input path). Always confirm joint type on the drawing — a fillet callout sized as leg is not interchangeable with a throat dimension.

Throat = 0.707 × leg (equal-leg fillet)

Rearranging for sizing from required throat:

leg z = requiredThroat / 0.707

Example: if structural analysis demands 5.0 mm effective throat, leg ≈ 5.0 / 0.707 ≈ 7.07 mm → round up to shop practice (8 mm leg is common). SC-001 returns two decimal places; fabrication still requires rounding to available wire size, WPS limits, and access constraints.

Strength check from design load

SC-001 uses a simplified shear-capacity model on the design throat area:

allowableShear = weldStrengthMpa / safetyFactor requiredThroat = designLoadN / (weldLengthMm × allowableShear)

Where weldStrengthMpa is the nominal weld metal strength ( electrode / process dependent ), and safetyFactor captures code partial factors and engineering margin. Allowable shear is treated as nominal strength divided by safety factor — a planning simplification; code clauses may specify different φ factors, directional loading, or combined stress.

designLoadN is total force transferred through the weld group in newtons; weldLengthMm is total effective weld length. For linear fillets along one edge, length is the weld run length. Complex weld groups (eccentric shear, parallel and transverse components) require manual equivalent load — SC-001 is single-result preview, not a full weld-group solver.

Utilization ratio

utilization = requiredThroat / (finalLeg × factor)

Utilization compares demand throat to capacity throat implied by the governing leg. Values near 1.0 mean the selected leg closely matches demand; low utilization means code minimum or rounding governs; utilization > 1.0 would indicate insufficient leg — SC-001 selects max(load leg, code min) so final designs should not exceed 1.0 after governing.

Use utilization to spot overweight welds (low value → save wire, heat, distortion) or margin-tight designs (high value → verify load path and NDT).

Code minimum legs (AWS / ISO framing)

Structural codes specify minimum fillet legs from base metal thickness to prevent under-welding thin members and excessive heat on thick ones. SC-001 interpolates approximate AWS D1.1 Table 2.1 nodes:

Material thickness (mm)Minimum fillet leg (mm, ref.)
≤ 63
6 – 125 (interpolated)
12 – 206 (interpolated)
> 208 (interpolated)

Step interpolation between nodes means a 10 mm plate yields a minimum between 5 and 6 mm — not a discontinuous jump. These nodes are reference estimates for v1.0.0; the AWS D1.1 edition adopted on the project, joint type, and special provisions (tubular, seismic, bridge) may differ.

ISO 2553 symbol conventions and ISO 5817 quality levels (B, C, D) govern acceptance criteria and throat execution tolerance — SC-001 does not map quality level to effective throat reduction. Frame ISO requirements in the WPS and inspection plan separately.

When effective throat matters

Theoretical throat (0.707 × leg) assumes perfect fusion to the root with full face height. Real welds may have:

  • Concave profile — reduced effective throat
  • Root lack of fusion or gap — reduced capacity
  • Oversized leg with unchanged throat — wasted heat input
  • Deep penetration beyond root — increased effective throat (benefit, if qualified)

When quality level C or B under ISO 5817 applies, inspectors measure actual throat; underrun relative to theoretical throat increases utilization in service. For fatigue-critical joints, use qualified effective throat from procedure qualification records (PQR), not leg alone.

SC-001 sizes on theoretical throat and code minimum leg — appropriate for preliminary design and quoting. Final substantiation requires WPS, qualified welders, and NDT per contract code.

Governing leg selection

legFromLoad = requiredThroat / factor finalLeg = max(legFromLoad, minLegFromTable)

The calculator reports both contributors: legFromLoadMm and minLegMm. Whichever is larger governs. Thin, lightly loaded plates often govern on code minimum; heavy loads on thick plate govern on structural demand.

Output includes finalLegMm and finalLegIn via deterministic unit conversion — exercises dimensional consistency in the engine. Round up to standard leg increments (1 mm or 1/16 in) before detailing.

Welding in quotes and labor hours

Weld size drives deposition volume, passes, distortion control, and inspection scope — all hour drivers. Use SC-001 early in estimating to avoid under-specifying legs that fail code check or over-specifying legs that inflate wire and heat. Translate weld length × passes × travel speed into labor hours, then apply loaded welder cost from SC-010 in SC-012.

Frequently asked questions

Is SC-001 certified to AWS D1.1?

No. SC-001 uses approximate AWS D1.1 Table 2.1 minimum leg nodes for engineering preview. It does not replace code compliance review, WPS qualification, or inspector acceptance. Always use the code edition specified on the contract.

Why is cos(45°) equal to 0.707 for fillet welds?

On an equal-leg fillet, the theoretical throat lies along the 45° bisector between legs. Throat equals leg × cos(45°) ≈ leg × 0.707. Unequal-leg filts or skewed joints need geometry-specific throat calculation — not the default 0.707 factor.

What safety factor should I use?

Depends on code, load type (static vs fatigue), and risk category. SC-001 defaults are user-entered; a reference starting point for static preview is 1.5–2.0 on nominal weld strength. Seismic, crane, and pressure applications need code-specific factors — do not rely on a generic preview value.

When does code minimum govern over load-based leg?

When minLegFromTable exceeds legFromLoad — common on thin members with moderate loads. SC-001 returns max of both. Check utilization: low values indicate code or rounding governs; required throat is well inside provided capacity.

Does SC-001 handle butt welds?

Butt joint type uses factor 1.0 instead of 0.707 — throat equals the computed required dimension along the butt path. AWS minimum fillet table does not apply to butt joints; min leg from table is fillet-specific. Select joint type explicitly in the tool.
