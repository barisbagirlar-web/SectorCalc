What is ISO 286 Fits?

ISO 286 Fits is the ISO tolerance system for linear sizes defining fundamental deviations (e.g., H7, g6) and tolerance grades IT01 through IT18. In engineering practice, it is used to specify fit classes between mating parts such as clearance, transition, and interference fits.

PropertyValue
StandardISO 286-1
FormulaUpper/Lower deviation from tables
Unitsmm, um
Used InMechanical design, bearing housings, shaft-bore assemblies

How ISO 286 Fits Works

Designers pick a hole basis (for example H7) and a shaft deviation (for example g6) to create a standardized fit class.

ISO 286 tables replace ad-hoc bilateral tolerances with interchangeable, globally recognized classes.

Key Variables

  • IT grade: Tolerance magnitude class (IT6, IT7, …).
  • Fundamental deviation: Letter code locating the tolerance zone (H, g, p, …).
  • Fit type: Clearance, transition, or interference resulting from the pair.

Common Mistakes

  • Mixing hole-basis and shaft-basis conventions in one assembly without documenting which features own the basis.
  • Selecting an interference fit without checking material stress or assembly temperature.
