Published studies

No verified case studies are published yet. When a study clears the evidence checklist below, it appears in this section with method, tool version, measured vs not-measured scope, and a citable source.

Evidence checklist (required before publish)

  1. Named method (standard or documented procedure) and SectorCalc tool ID / version used.
  2. Input bounds and units that a third party can reproduce.
  3. Clear split between measured shop data and calculated preview outputs.
  4. Explicit “what was not measured” paragraph (no silent gaps).
  5. Permission to publish from the data owner; anonymization rules stated when required.
