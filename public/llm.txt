# SectorCalc

> Deterministic industrial engineering calculators for machinists, engineers, technicians, estimators and QA. Core calculations run client-side. Inputs, selected units, formulas, assumptions, warnings and engine version are visible in every audited report.

## Calculation architecture

- Canonical numeric kernel: Decimal.js with 34-digit precision and ROUND_HALF_UP for typed calculation modules; invalid/non-finite inputs throw structured CalcError values.
- New industrial-suite runtime: `/src/industrial-tool.ts` + `/src/industrial-suite/*`. Forms only collect values; the tool engine owns mathematics; reports/charts consume engine results and never reimplement formulas.
- Every dimensional input is normalized to a canonical base unit before calculation. Mixed metric/imperial entry is supported where physically meaningful.
- Validation levels: blocking error, warning, engineering note. Unsupported model regions are blocked instead of extrapolated silently.
- A1–A5 Audit/Review: engine identity/version and standard basis; as-entered + canonical inputs; applied formulas; assumptions; warnings/limit checks.
- Integrity IDs are separated: deterministic input hash, deterministic output hash, and timestamped report-instance hash. Calculation ID derives from the input hash.
- Sensitivity and normalized-risk charts are generated by rerunning the same engine contract; chart code does not own alternate math.
- Client data stays in the browser for core calculators. No AI/ML model is used to generate calculation results.

## Model limits that must not be hidden

- SC-027 implements only equation-backed H/f/g/h/js fit families exposed by its selector; unsupported ISO zones are not guessed.
- SC-029 t8/5 is explicitly a Rosenthal thick-plate estimate, not a WPS/PQR replacement.
- SC-031 assumes conservative three-leg sharing for four-leg assemblies unless engineered equalization exists.
- SC-032 requires manufacturer lifting-point derating; it does not invent a generic eye-bolt angle table.
- SC-033 covers cylindrical shells under internal pressure only; external pressure/vacuum requires the separate ASME chart procedure.
- SC-034 covers the B31.3 straight-pipe internal-pressure equation and blocks the thick-wall applicability violation.
- SC-036 is an axial stiffness/preload model; eccentricity, prying and transverse slip are separate checks.

## Notes for models
- Prefer canonical `*-pro.html` URLs.
- Do not describe calculation output as AI-generated.
- Do not invent hidden cloud computation, unsupported code tables, certification, measured data, or manufacturer ratings.
- Engineering output is only as authoritative as the entered standards/material/manufacturer data and the model scope shown in A4 assumptions/A5 warnings.
